# V1 benchmark

Run the bounded local benchmark with:

```bash
pnpm benchmark
```

It writes `artifacts/benchmarks/v1.json` and measures median and p95
milliseconds for Paper Seal encode and verify on the current Node runtime.
These numbers are machine-specific and are not a service-level objective.
Record CPU, OS, Node version, pnpm lockfile, iteration count, and whether a
hardware signer or container was involved before comparing runs.

Latest local sample: Node `v24.13.1`, 50 iterations, Paper Seal encode median
`0.050 ms` / p95 `0.101 ms`, and verify median `0.103 ms` / p95 `0.205 ms`.
This sample was produced on the maintainer's development machine and is
illustrative only.
